# 知识库使用指南

欢迎使用 **知识库 (ZhiShiKu)** —— 一个智能的云端知识管理系统。

## 核心功能

### 🔍 语义搜索

知识库使用向量嵌入技术，支持基于语义的智能搜索。你不需要精确匹配关键词，只需描述你想要找的内容，系统就能找到最相关的知识文档。

### 🤖 自动修订引擎

当你提交新知识时，系统会自动分析新内容与现有知识的关系：

- **补充 (supplement)**：新内容是对已有文档的扩展，会智能合并到已有文档中
- **更新 (update)**：新内容是对已有文档的更正，会替换/修改相关部分
- **新建 (new)**：新内容是全新的主题，会创建新文档

### 📁 GitHub 同步

所有知识文件以 Markdown 格式存储在 GitHub 仓库中，每次变更都会自动提交，保留完整的修订历史。

## 访问方式

知识库提供两种访问协议：

1. **REST API** - 标准 HTTP API，适用于各种应用集成
2. **MCP SSE** - Model Context Protocol，适用于 AI 助手集成（如 Claude Desktop）

## 文件格式

所有知识文档使用 Markdown 格式，包含 YAML frontmatter 元数据：

```markdown
---
title: 文档标题
tags:
  - 标签1
  - 标签2
created_at: "2024-01-01T00:00:00Z"

    note: 初始创建
---

# 正文内容

这里是文档的正文...
```
